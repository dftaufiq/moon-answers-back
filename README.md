A small Python program that writes the one line the Moon says back to everyone who has ever stared up at it — an answer to the wishes, the howls and the late-night promises — to /output/entry.txt. The line is fixed and deterministic: the same 174-character line every run.

## Run it

```sh
python3 main.py
```
